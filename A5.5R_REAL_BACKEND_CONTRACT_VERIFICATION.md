## Executive summary

**Final status: BLOCKED.**

No request was sent to a real backend. The safety gate (brief §5) failed before any request, for three reasons:
1. **The target is ambiguous.** The new CMS `API_HOST` and the legacy `APIGATEWAY_URL` are different hosts, and which one serves `/api/v1/cms/contents` is undecided (OD-02).
2. **The environment is unconfirmed.** Both host names only *look* non-production.
3. **There is no test account** available to the verifier.

Mocks passing is not real evidence, so this phase is not GO-WITH-RISKS.

Delivered instead:
- **A read-only live verification harness** (`npm run test:live`). It drives the production path — request scope → use case → repository → `GatewayClient` — against a real gateway. It refuses to run without an explicit non-production confirmation, a host allow-match and a test account, and blocks every method except GET on the content endpoint and POST on the auth endpoints.
- **The harness was self-tested against the local mock** (all 10 steps ran, including 401 → refresh → retry-once). The architecture itself is unchanged and green (388 tests, build, bundle, A5.1–A5.4 runtime regression).

## Contract differences found (without the backend)

1. **Two gateways, one target** (OD-02, High). `API_HOST` ≠ `APIGATEWAY_URL`. The feature path assumes the legacy `/api/v1/cms/*` API is reachable under `API_HOST`, and that is unverified.
2. **Auth contract default is `b0`** (High). If the Content API is the legacy gateway, login / refresh must be `legacy-v1`. That contract has **no refresh endpoint**, so sessions end at token expiry (A5.1 degrade mode).
3. **`API_HOST` carries a path prefix and uses plain `http`** (Medium). Paths are appended to the prefix. TLS to the gateway is not used; whether it's acceptable inside the private network is a security / ops decision.
4. **API key is sent; legacy sends none** (Medium, OD-03). Harmless if ignored; rejected if the gateway forbids unknown headers (unknown).
5. **GET body not sent** (Medium, OD-31). The same as A5.5 RK-A55-02.
