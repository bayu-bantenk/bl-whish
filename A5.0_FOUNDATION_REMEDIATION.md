## 1. Executive summary

- Removed the 7 DexanKit template feature packages, their `/dashboard/*` routes, the template profile route and the dead dashboard gateway client. **OD-17 = RESOLVED: DexanKit template feature packages are removed because they are outside the GPOS legacy scope.**
- The browser no longer calls the gateway. Auth flows (register, forgot, reset, activation) now run through Server Actions. Login runs through the better-auth server endpoint, which no longer returns tokens.
- `API_HOST`, `KONG_API_KEY` and `APP_KEY` are no longer inlined into the client bundle. A bundle scan finds 0 hits.
- Every module that touches the gateway, tokens or env secrets is now marked `server-only`.
- A hardcoded SonarQube token was removed from the `Jenkinsfile`. **Rotating it is required**, because it stays in git history.
- Gate results: lint 355 errors → **0**; tests FAIL → **PASS (2/2)**; typecheck PASS; build PASS.
- Added a CI quality gate (`npm run quality`) to the image build.
- Husky hooks are installed. `commit-msg` PASSES. `pre-commit` is BLOCKED because `prettier` is not a declared dependency (it needs approval, and the registry returns 403).
- DD-01..DD-07 are fixed in all 4 rule mirrors. The README and `components.json` are updated, and the dashboard-shell rule is documented.
- No dependencies were added. `reactflow` and `shell-quote` were removed because they are now unused.
